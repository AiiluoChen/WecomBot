1 方案定位与设计哲学

🎯 核心业务闭环

⚡ Agent 内部决策与调用链路解析
Step 1 · 迎宾触发 (Event Hook)

检测到客户新会话建立，直接推送静态模板 WELCOME_NOTICE_TPL。不消耗大模型 Token，毫秒级下发三要素收集模板与服务规范。

Step 2 · 智能实体抽取与工具分发

客户输入：“11月2日 北京门店 陈麻子”

→ Agent 决策: 调用 tool query_pan_link
→ 参数: {"shoot_date": "2026-11-02", "store": "北京门店", "customer_name": "陈麻子"}

Step 3 · 数据层本地检索与状态返回

在 photo_delivery.csv 中匹配到该记录。读取到网盘分享链接和密码，状态标记为 ready。

Step 4 · 标准化格式渲染与下发

Agent 获得工具返回结果后，先回复快捷确认“好的，亲亲”，随后依据预设模版组装百度网盘专属分享卡片文案推送给客户。

分支场景 A · 闲聊意图触发

客户说：“你们店在哪呀 / 辛苦啦” → Agent 判定不需要调取工具，直接扮演萌萌客服人设，亲切回复闲聊，维持客情关系。

分支场景 B · 转人工兜底触发

客户说：“修得太丑了想重修 / 给我人工电话” 或连续两次未查到底片 → 自动触发 escalate_to_human 工具，安抚客户并向真人客服群发出告警。

3 纯原生极简 Agent 核心引擎

为什么拒绝 LangChain？因为第三方黑盒层层封装、版本频繁破坏、报错难以追踪。纯原生 Agent 仅使用 OpenAI 兼容规范的标准 client.chat.completions.create，整个引擎精炼至 60 行内，清晰可见、易于调试： 

Python (Native Loop)class NativeAgent:
    def __init__(self, system_prompt: str, tools: list, tool_map: dict):
        self.system_prompt = system_prompt
        self.tools = tools          # JSON Schema 定义
        self.tool_map = tool_map    # 函数映射字典 {"query_pan_link": fn}

    def chat(self, user_msg: str, history: list) -> str:
        messages = [{"role": "system", "content": self.system_prompt}] + history
        messages.append({"role": "user", "content": user_msg})

        # --- 极简 Tool-Calling 循环 ---
        while True:
            response = client.chat.completions.create(
                model=os.getenv("MODEL_NAME", "deepseek-chat"),
                messages=messages,
                tools=self.tools,
                tool_choice="auto"
            )
            msg = response.choices[0].message

            # 如果没有工具调用，说明是大模型直接回答（闲聊或追问），直接返回
            if not msg.tool_calls:
                return msg.content

            # 如果触发了工具调用，逐个执行工具并将结果回填
            messages.append(msg)
            for tool_call in msg.tool_calls:
                fn_name = tool_call.function.name
                args = json.loads(tool_call.function.arguments)
                
                # 执行本地对应 Python 函数 (如查 CSV、发转人工通知)
                tool_result = self.tool_map[fn_name](**args)
                
                messages.append({
                    "role": "tool",
                    "tool_call_id": tool_call.id,
                    "content": json.dumps(tool_result, ensure_ascii=False)
                })
            # 携带工具结果继续下一轮循环，让大模型生成最终回复话术

🎭 客服人设 System Prompt 规范
System Prompt你叫萌萌，是“旅咔修图中心”的企业微信在线客服。你的语言风格必须温柔体贴、耐心、称呼客户为“亲亲”。
服务守则：
1. 查片场景：当客户发来拍摄信息时，尽可能提取“拍摄时间”、“门店或手机后4位”、“姓名”，并调用 query_pan_link 工具查询。若缺少信息（如只发了姓名），请温柔引导客户补齐。
2. 闲聊场景：日常问候、致谢或简单交流，请直接以萌萌的口吻温柔回复，切勿随意调用工具。
3. 转人工场景：遇到客户表达不满、要求修改复杂精修方案、或明确提出找人工客服时，必须调用 escalate_to_human 工具，并在回复中真诚安抚客户耐心等待真人接听。
4. 格式严谨性：当获得网盘链接后，严格按照标准模板输出（包含文件名、链接、提取码及提示文案）。

无论目标机器是 Ubuntu、CentOS 还是腾讯云、阿里云，只要有 Docker，一键执行即可：

# 3. 一键构建并启动后台运行
